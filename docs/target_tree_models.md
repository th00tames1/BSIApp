# 수간 복원 모델과 처리 기록

앱 v0.4.3은 주 분할 모델을 유지하고, 누락된 위쪽 수간을 확인하는 보조 모델을 추가한다.
사진 번호나 검증 좌표를 운영 코드에 사용하지 않는다.

| 수간 복원, YOLO11n 640 | `assets/models/bsi_tree_rescue_yolo11n_640.onnx` | `ae535e3194b259482f3d99d5fbdf387fdc9623d89af93bffa338fae182f999dd` |

보조 모델은 기존 보관본 `BSI_handoff/3_model/exp_F_clean/weights/best.onnx`와 바이트가 같다.
새 학습이나 기존 연구 데이터 변경은 하지 않았다. 메타데이터는 Ultralytics 8.4.21,
YOLO11n-seg, export `2026-06-10T03:46:31`, 클래스 `0: soot, 1: tree`다.
크기는 11,627,297바이트, FP32 고정 입력 `[1,3,640,640]`, 출력은 `[1,38,8400]`과
`[1,32,160,160]`이다. ONNX opset 19의 표준 연산을 사용한다.

## 반영 조건

1. 주 모델은 실제 마스크에서 대상목을 선택한다. 탭은 검출 상자 포함 여부보다 실제 수간까지의 거리를 우선하며, 먼 위치를 지정하면 기권한다.
2. 수간 연결성은 8방향으로 판단한다. 선택 수간 밖 그을음은 표시·계측에서 제외한다.
3. 주 모델의 상부 부분영상은 최대 한 번 재추론한다. 원본과 하부 수간을 공유하는 실제 검출만 원래 격자로 복원한다.
4. 보조 모델의 수간은 원래 대상의 90% 이상을 덮고, 보조 수간 자체의 65% 이상이 원래 대상과 겹쳐야 한다. 별개 인스턴스 침범도 검사한다.
5. 수간 상단에서 높이의 60~85%만큼 내려온 구간에서, 양쪽 폭의 75% 이상을 공유하는 단일 줄기가 폭에 비례한 연속 행으로 확인되어야 한다. 그 공유 구간 위의 검출만 추가한다. 보조 모델의 지면·추가 밑동은 반영하지 않는다.
6. 기존 갈래 사이의 빈 공간을 유지하고, 새로 추가한 영역 중 원래 수간에 연결되지 않는 조각을 제거한다. 검출 상자 밖 프로토타입 응답을 새 수간이나 개체 동일성 근거로 사용하지 않는다.
7. 수동 제외·지표면은 모든 추론 후 적용한다. 자동 직경·DBH 축척의 참조는 동일 보정을 거친 주 모델 수간으로 유지하며, 복원된 최종 형상에서 흉고 위치가 갈라지면 기권한다.

추가 추론은 부분영상 한 번과 보조 모델 한 번으로 제한된다. 보조 모델 실패 시 주 모델의 유효 결과를 유지한다.
원시 분석 JSON의 `treeRescues`, `stemReference`, `dbhMeasurement`와 참조 마스크에 처리 근거를 저장한다.

## 검증 해석

보관된 현장 사진은 알려진 오류 사례의 회귀 자료다. 이 자료의 통과를 별도 시험 집단에서의 일반화 성능으로 해석하지 않는다.
004의 양갈래를 복원하는 모델을 찾는 과정에서 다른 보관 모델과 부분영상도 비교했다.
014 서쪽에서 보조 모델이 지면을 포함한 반례를 발견해, 밑동 보전과 지면 제외 회귀 검사에 추가했다.
최초 중첩 사례는 원본이 없어 합성 마스크와 사용자 제외 기능으로 검증하며, 실제 해당 현장 사진을 검증했다고 주장하지 않는다.
