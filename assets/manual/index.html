이 설명서의 화면은 Android 기준입니다. iPhone도 화면 구성과 조작 방법이 같으며, 다른 부분은 본문에 따로 적었습니다.

1

시작하기

준비물

  • Android 휴대폰 또는 iPhone
  • 수고봉: 노랑·흰 눈금 수고봉(1 m 간격) 또는 적백 폴(빨강·흰 0.2 m 간격)
  • 흉고직경 측정 도구(직경 테이프 등). 실측값을 입력하면 판정 정확도가 높아집니다.

설치

Android

  1. GitHub 릴리스 페이지(github.com/th00tames1/BSIApp/releases)에서 Android 설치 파일(.apk)을 다운로드합니다(약 146 MB, Wi-Fi 권장).
  2. 다운로드한 파일을 실행하고, 안내 창이 표시되면 이 출처 허용을 켠 후 설치합니다. 기존 BSI_app과는 별도의 앱으로 설치되며, 기존 앱의 조사 기록은 그대로 남습니다.

iPhone

  1. App Store에서 BSI 현장조사 앱을 검색해 설치합니다.

첫 실행

처음 실행하면 위치와 카메라 권한을 요청합니다. 위치는 정확한 위치로 허용합니다. iPhone에서는 앱을 사용하는 동안을 선택하고 정확한 위치를 켭니다.

2

지도 화면

앱을 실행하면 지도 화면이 표시됩니다. 조사지 선택, 조사목 추가, 기록 조회를 모두 이 화면에서 시작합니다.

1
조사지 이름 현재 조사지와 조사목 수, 벌채 수를 표시합니다. 누르면 조사지를 전환하거나 새로 등록합니다.
2
조사 기록 저장한 조사목 목록을 표시합니다.
3
설정 나침반 기준, 수고봉 눈금 간격, 백업, 업데이트를 설정합니다.
4
조사목 위치 존치는 초록, 벌채는 빨강으로 표시됩니다. 누르면 요약이 열립니다.
5
조사지 경계 경계 파일을 불러오면 표시됩니다(8장).
6
지도 레이어 일반·위성 지도 전환과 경계 파일 불러오기
7
내 위치 현재 위치로 지도를 이동합니다.
8
조사목 추가 다음 번호로 촬영 화면을 실행합니다. 조사지가 없으면 새 프로젝트로 표시됩니다.

작성 중인 조사

촬영한 사진은 즉시 저장됩니다. 앱이 종료되거나 전화를 받은 뒤에도 지도 위쪽에 작성 중인 조사가 표시되며, 계속을 누르면 이어서 촬영합니다. 삭제를 누르면 해당 조사를 삭제합니다.

3

조사지 등록

  1. 지도 화면에서 새 프로젝트를 누릅니다. 이미 조사지가 있으면 조사지 이름을 누른 뒤 오른쪽 위 +를 누릅니다.
  2. 조사지명을 입력합니다(필수, 기존 조사지와 같은 이름은 사용할 수 없음).
  3. 위치는 필요한 경우에만 입력합니다.
  4. 다음 조사목 번호는 새 조사지라면 기본값을 그대로 둡니다.
  5. 프로젝트 생성을 누릅니다.

조사목 번호는 001부터 순서대로 자동 부여되며, 촬영 화면 위쪽에서 변경할 수 있습니다.

참고

지도에는 선택한 조사지의 조사목만 표시됩니다. 프로젝트를 삭제해도 조사목 기록은 지워지지 않습니다.

4

촬영

화면 구성

지도 화면의 조사목 추가를 누르면 촬영 화면이 열립니다.

1
조사목 번호 누르면 번호를 변경합니다.
2
수종 누르면 수종을 선택합니다. 기본은 소나무이며, 마지막에 선택한 수종이 다음 조사목에 적용됩니다.
3
GPS 상태 초록이면 촬영 지점이 기록됩니다. 주황은 정확도 낮음, 빨강은 신호 없음입니다.
4
나침반 휴대폰이 향한 방위를 표시합니다. 누르면 진북과 자북 기준이 전환됩니다. iPhone은 진북으로만 표시합니다.
5
줌 배율 0.6×는 근거리에서 수간 전체를 담을 때, 2×와 3×는 원거리의 대상목을 촬영할 때 사용합니다.
6
방위 버튼 노랑은 촬영할 방위, 초록은 촬영을 마친 방위입니다. 바로 위에 현재 방위와 촬영 수가 표시됩니다.
7
셔터 촬영하면 다음 방위로 자동 전환됩니다.
8
갤러리 기존에 촬영한 사진을 방위를 지정해 불러옵니다.
9
노출 보정 화면이 지나치게 어둡거나 밝을 때만 사용합니다.
10
AI 분석 1장 이상 촬영하면 활성화됩니다.

촬영 순서

  1. 대상목 옆에 수고봉을 수직으로 세웁니다.
  2. 지도 화면에서 조사목 추가를 누릅니다.
  3. 북쪽 면부터 촬영합니다. 셔터를 누를 때마다 북, 동, 남, 서 순서로 다음 방위가 선택됩니다.
  4. 재촬영할 방위가 있으면 해당 방위 버튼을 누르고 촬영합니다(기존 사진을 대체).
  5. 4방위 촬영을 마치면 AI 분석 · 4/4를 누릅니다.

지형 여건상 일부 방위를 촬영하지 못한 경우 촬영한 방위만으로 분석하고, 나머지는 결과 화면에서 야장 값을 입력합니다(6장). 촬영 중 앱이 종료되어도 촬영한 사진은 보존됩니다(2장).

촬영 요령

  • 촬영 범위 근원부(지표면)부터 그을음 최고 높이까지 한 화면에 들어오도록 촬영합니다. 촬영 거리는 그을음 높이에 따라 대략 2~8 m입니다.
  • 대상목 위치 대상목을 화면 가운데에 둡니다. 인접목이 가운데에 있으면 인접목을 대상목으로 인식할 수 있습니다.
  • 수고봉 눈금 눈금 경계가 2개 이상 보여야 높이를 정확히 계측합니다.
  • 순광 촬영 태양을 등지고 촬영합니다. 역광이 감지되면 수간 기준 노출로 자동 재촬영하며, 수간이 여전히 검게 촬영되면 촬영 위치를 옮깁니다.
  • GPS 확인 GPS 표시가 초록일 때 촬영합니다. 하늘이 트인 곳에서 잠시 기다리면 초록으로 바뀝니다.
수고봉

적백 폴(0.2 m 간격)은 자동으로 인식합니다. 노랑·흰 수고봉의 눈금 간격이 1 m가 아니면 설정 › 수고봉 눈금 간격을 실제 값으로 변경합니다.

5

분석 결과

AI 분석을 누르면 방위별로 수간, 그을음, 수고봉 눈금을 검출합니다. 분석은 휴대폰 안에서 처리되며 4방위에 약 20초가 걸립니다(기기에 따라 다름).

1
전체 재분석 모든 방위를 다시 분석합니다.
2
판정표 판정표에서 이 조사목의 해당 칸을 표시합니다.
3
지도 저장하지 않고 지도로 이동합니다. 사진은 작성 중인 조사로 남습니다.
4
흉고직경 사진에서 자동 추정한 값이 입력되어 있습니다. 실측값을 입력하면 판정이 즉시 다시 계산됩니다.
5
고사 확률과 판정 고사 확률이 30 % 이상이면 벌채 권고입니다.
6
BSI 4방위 그을음 높이(m)와 그을음 비율을 곱한 값의 합입니다.
7
방위 선택 방위별 그을음 비율이 표시되며, 누르면 해당 방위의 사진과 계측값을 표시합니다.
8
분석 사진 분석 내용을 색으로 표시합니다.
저장

화면 맨 아래 저장을 눌러야 기록됩니다.

분석 사진 읽는 법

  • 수간
  • 그을음
  • 수고봉 눈금 경계
  • 그을음 최고 높이
  • 흉고직경 위치(지상 1.3 m)
  • 지표면(근원부)

방위별 계측값

위쪽 방위 선택에서 방위를 누르고 화면을 아래로 내리면, 분석 사진 아래에 해당 방위의 계측값이 표시됩니다.

  • 그을음 높이 지표면에서 그을음 최고점까지의 높이(m)
  • 그을음 비율 그을음 최고 높이 아래 수간 중 그을린 면적의 비율
  • 수간 높이 사진에 보이는 수간의 높이(m)
  • 수고봉 스케일 높이 환산 기준(px/m). 수고봉이 검출되지 않으면 표시되지 않습니다.
판정 기준

BSI와 흉고직경으로 판정표(BSI 1~25, 흉고직경 20~58 cm)에서 고사 확률을 산출합니다. 흉고직경이 없으면 판정하지 않습니다.

6

결과 보정

자동 분석 결과가 부정확한 방위는 결과 화면의 방위 선택에서 해당 방위를 누른 뒤, 분석 사진 아래의 방위 수정에서 보정합니다. 저장한 뒤에는 조사목 상세 화면 오른쪽 위의 새로고침(이미지 재분석)으로 다시 분석할 수 있습니다.

지표면·대상목 지정

방위 수정의 지표면·대상목 지정을 누르면 보정 화면이 열립니다.

  • 지표면 기준선을 근원부 지표면에 맞춥니다. 기준선 아래는 수간에서 제외됩니다.
  • 대상목 인접목이 검출된 경우 대상목의 수간을 누릅니다.
  • 역광 보정·밝기·대비 사진이 어두워 수간이 제대로 검출되지 않을 때 조정합니다.

설정을 마치면 적용 후 재분석을 누릅니다.

계측값 직접 입력

방위 수정의 계측값 직접 입력을 누르면 입력 창이 열립니다. 그을음 최고 높이(m)와 그을음 면적비(%)를 입력하면 자동 분석값 대신 BSI 산출에 사용됩니다. 사진과 분석 표시는 유지됩니다.

미촬영 방위 입력

사진이 없는 방위가 있으면 결과 화면의 분석 사진 아래에 미촬영 방위 입력이 표시됩니다. 해당 방위를 누르고 야장의 그을음 최고 높이와 그을음 면적비를 입력하면 BSI 산출에 포함됩니다.

수고봉이 검출되지 않은 경우

수고봉이 검출되지 않은 방위가 있으면 결과 화면의 방위 수정 아래에 흉고직경으로 높이 추정이 표시됩니다. 화면 위쪽 흉고직경 칸에 실측값을 입력한 뒤 이 버튼을 누르면 수간 폭으로 높이를 환산합니다. 수고봉 기준보다 정밀도가 낮으므로 가능하면 재촬영합니다.

수고봉 눈금 간격

결과 화면과 조사목 상세 화면 아래쪽의 수고봉 눈금 간격을 누르면 변경할 수 있습니다. 값을 선택하면 수고, 그을음 높이, 통합 BSI의 변경 예상값을 먼저 표시합니다.

적백 폴로 계측한 방위는 0.2 m가 자동 적용되어 이 값의 영향을 받지 않습니다.

주의

간격이 실제와 다르면 모든 높이 계측값이 같은 비율로 달라집니다. 계측값이 비정상적이라는 안내가 표시되면 먼저 이 값을 확인합니다.

7

조사 기록

지도 화면 오른쪽 위의 조사 기록(시계 모양 버튼)을 누르면 저장한 조사목이 최신순으로 표시됩니다. 항목을 누르면 상세 화면이 열립니다.

오른쪽 위 공유 버튼을 누르면 모든 기록을 CSV 파일로 내보냅니다. 공유 창에서 메일, 메신저, 클라우드 저장소 등을 선택합니다.

주의

목록에서 항목을 왼쪽으로 밀면 확인 절차 없이 즉시 삭제됩니다. 삭제한 기록은 복구할 수 없습니다.

조사목 상세

조사 기록 목록에서 항목을 누르거나, 지도에서 조사목 위치를 누른 뒤 상세 보기를 누르면 열립니다.

항목기능
새로고침(오른쪽 위)이미지 재분석. 저장된 사진을 다시 분석해 BSI를 새로 산출합니다. 직접 입력한 방위와 흉고직경은 유지됩니다.
공유(오른쪽 위)이 조사목만 CSV 파일로 내보냅니다.
휴지통(오른쪽 위)확인 후 조사목을 삭제합니다.
흉고직경수정하면 고사 확률과 판정이 다시 계산됩니다.
수고, 그을음 높이기록과 CSV에만 쓰이는 값입니다. 통합 BSI는 바뀌지 않습니다.
GPS 좌표위도와 경도를 수정합니다. 두 칸을 비우면 좌표와 지도 표시가 삭제됩니다.
8

지도 유형과 조사지 경계

지도 화면 오른쪽 아래의 지도 레이어 버튼(2장 지도 화면의 6번)을 누르면 지도 레이어 창이 열립니다. 지도에서 조사목 위치를 누르면 요약이 열리며, 상세 보기를 누르면 조사목 상세 화면으로 이동합니다.

  • 지도 유형 일반과 위성 중에서 선택합니다. 지도 배경을 불러오려면 인터넷 연결이 필요합니다.
  • 경계 파일 불러오기 SHP(.shp와 .prj, 또는 이를 묶은 .zip), KML/KMZ, GeoJSON 파일을 불러옵니다. 경계는 조사지별로 저장됩니다.
  • 좌표계 선택 .prj 파일이 없으면 좌표계 선택 창이 표시됩니다. 자료 제공처의 좌표계를 선택합니다.
9

백업과 기기 변경

백업 만들기

  1. 지도 화면 오른쪽 위의 설정을 열고 백업 내보내기를 누릅니다.
  2. 생성을 누릅니다. 조사 기록, 사진, 설정이 ZIP 파일로 저장됩니다.
  • Android 내장 저장공간 › Download › BSI_backup에 생성되며, 앱을 삭제해도 남습니다.
  • iPhone 완료 창의 공유를 누르고 파일에 저장을 선택해 iCloud Drive 등에 보관합니다.

백업이 3.5 GB를 넘으면 여러 파일로 분할됩니다.

권장

현장 조사를 마친 날마다 백업하고, 백업 파일을 PC나 클라우드 저장소에도 복사해 둡니다.

새 휴대폰으로 옮기기

  1. 기존 휴대폰에서 백업을 만듭니다.
  2. 백업 파일을 새 휴대폰으로 옮깁니다. Android는 Download › BSI_backup 폴더, iPhone은 파일 앱에서 접근할 수 있는 위치에 둡니다. 분할된 파일은 모두 옮깁니다.
  3. 새 휴대폰에 BSI 현장조사 앱을 설치합니다(1장).
  4. 설정 › 백업 불러오기에서 백업 파일을 선택합니다. 분할된 경우 모두 선택합니다.
  5. 불러오기를 누릅니다. 중복 기록은 제외하고 병합되며, 설정은 백업 값으로 대체됩니다.
참고

Android 파일 선택 창에 백업이 표시되지 않으면 왼쪽 위 메뉴에서 내장 저장공간 › Download › BSI_backup으로 직접 이동합니다.
